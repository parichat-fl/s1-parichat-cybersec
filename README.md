โดยใช้ข้อมูลต่อไปนี้

- ชื่อ Container: `69-s1-admin`
- Port: `80801`

### สิ่งที่ต้องส่ง

1. ภาพ Process การรัน PostgreSQL และ pgAdmin4
2. ภาพที่แสดงชื่อ Container `69-s1-admin`
3. ภาพที่แสดง Port `80801`
4. ภาพสถานะการเชื่อมต่อฐานข้อมูลใน pgAdmin4
