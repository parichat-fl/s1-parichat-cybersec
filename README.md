## การส่งภาพ Process PostgreSQL และ pgAdmin4

ให้นักศึกษาส่งภาพแสดง **Process การรัน PostgreSQL และ pgAdmin4** พร้อมทั้งแสดง **สถานะการเชื่อมต่อฐานข้อมูลที่อยู่ใน pgAdmin4** โดยต้องเห็นรายละเอียดที่สำคัญดังนี้

- ชื่อ Container: `69-s1-admin`
- Port: `80801`
- PostgreSQL ทำงานอยู่ (Running)
- pgAdmin4 ทำงานอยู่ (Running)
- แสดงสถานะการเชื่อมต่อ PostgreSQL ใน pgAdmin4 ว่าสามารถเชื่อมต่อฐานข้อมูลได้สำเร็จ

### สิ่งที่ต้องปรากฏในภาพ

1. ภาพ Docker Desktop หรือ Terminal ที่แสดง PostgreSQL และ pgAdmin4 กำลังทำงาน
2. เห็นชื่อ Container `69-s1-admin`
3. เห็น Port `80801`
4. ภาพหน้าจอ pgAdmin4 ที่แสดงการเชื่อมต่อกับ PostgreSQL สำเร็จ
5. ภาพต้องเห็นข้อมูลชัดเจนและสามารถตรวจสอบ Process และสถานะการเชื่อมต่อได้
